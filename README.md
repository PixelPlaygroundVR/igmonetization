## 🛠️ Running & Editing Locally

1. Clone this repo:
   ```bash
   git clone git@github.com:pixelplaygroundvr/igmonetization.git
   cd igmonetization
   ```
2. Open `index.html` in your browser to preview.
3. Make your changes to `index.html` (and other assets if added).
4. Commit & push:
   ```bash
   git add index.html
   git commit -m "Update Monetization Master Blueprint"
   git push origin main
   ```
5. Your updates auto-deploy to GitHub Pages.
